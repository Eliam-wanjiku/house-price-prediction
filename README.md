# House Price Prediction

## Overview
This project analyzes housing data and predicts house prices using Python.

## Dataset
The dataset includes:
- House size (square feet)
- Number of bedrooms
- Number of bathrooms
- House price

## Technologies Used
- Python
- CSV
- Pandas
- Scikit-learn

## Files
- house_prices.csv
- house_price_prediction.py
